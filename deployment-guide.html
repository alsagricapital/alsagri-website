/ACode & project setup

Get the files off this workspace and onto your computer.

A.1 — Download the project files

  1. In this workspace, look for the "⋮" menu or download icon in the toolbar (usually top-right of the file pane).
  2. Choose Download project (or "Export as ZIP"). A file like alsagri-website.zip will save to your computer's Downloads folder.
  3. Unzip it (double-click on Mac, right-click → "Extract All" on Windows). You'll get a folder with these files inside: 
    alsagri-website/
├── index.html
├── app.jsx
├── data.jsx
├── sections.jsx
└── tweaks-panel.jsx
  4. Move that folder somewhere sensible. I recommend:
    • Mac: ~/Documents/projects/alsagri-website
    • Windows: C:\Users\YourName\Documents\projects\alsagri-website

A.2 — Install your tools

You need three pieces of software. Install them in this order.

ToolWhat it isWhere
VS Code The text editor you'll use to view and tweak files. code.visualstudio.com
Git The tool that uploads your code to GitHub. git-scm.com/downloads
Node.js (optional, for running locally) Lets you run a small local web server to preview the site. nodejs.org — pick "LTS"

For each one: download → open the installer → click Next / Continue / Install on every screen. Default settings are fine.

A.3 — Verify the installs work

Open your terminal:

  • Mac: press ⌘ + Space, type Terminal, hit enter.
  • Windows: press ⊞ Win, type PowerShell, hit enter.

Type each of these commands (one at a time, press enter after each):

$ git --version
# expected output: git version 2.something

$ node --version
# expected output: v20.something

$ npm --version
# expected output: 10.something
!

If any command says "command not found", close and reopen the terminal. If still broken, the install didn't finish — reinstall that tool.

A.4 — Run the website locally

This lets you preview the site on your own computer before publishing.

  1. In your terminal, navigate into the project folder: 
    $ cd ~/Documents/projects/alsagri-website
# Windows: cd C:\Users\YourName\Documents\projects\alsagri-website
  2. Start a tiny local server using a built-in Node tool: 
    $ npx serve .
    The first time it'll ask "Ok to proceed? (y)" — type y and enter.
  3. It will print something like http://localhost:3000. Open that URL in your browser. Your site is now running locally.
  4. To stop it: in the terminal, press Ctrl + C.
TIP

You can also just double-click index.html and open it in your browser. That works for previewing, though some advanced features depend on it being served over http://.

/BGitHub

A free place to store your code online. It's where deployment platforms read from.

B.1 — Do you need a GitHub account?

Yes. Both Netlify and Vercel deploy directly from GitHub. It's also a free, versioned backup of your code.

B.2 — Create the account

  1. Go to github.com and click Sign up.
  2. Use your email, pick a username (e.g. alsagri or alsagricapital), set a password. Verify your email.
  3. Choose the Free plan when asked.

B.3 — Create a new repository

  1. Once logged in, click the + icon in the top-right → New repository.
  2. Fill in:
    • Repository name: alsagri-website
    • Description: "Alsagri Capital — Saudi market analysis"
    • Public (selected by default — fine, deployment platforms need this on the free tier)
    • Leave the README / .gitignore / license boxes unchecked — your folder already has files.
  3. Click the green Create repository button.
  4. You'll land on an empty repo page with setup instructions. Keep this tab open — you'll need the URL at the top, which looks like: 
    https://github.com/YOUR-USERNAME/alsagri-website.git

B.4 — Upload your code (the first push)

This is the part beginners always find confusing. Just follow the lines in order — copy/paste each one into your terminal.

  1. Make sure you're inside the project folder in the terminal: 
    $ cd ~/Documents/projects/alsagri-website
  2. Tell Git who you are (one time only on this computer): 
    $ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"
    Use the same email as your GitHub account.
  3. Initialize Git, stage all the files, and make your first commit: 
    $ git init
$ git add .
$ git commit -m "Initial commit"
$ git branch -M main
  4. Connect to GitHub and push (replace YOUR-USERNAME): 
    $ git remote add origin https://github.com/YOUR-USERNAME/alsagri-website.git
$ git push -u origin main
    The first push will ask you to log in. Modern GitHub uses a browser pop-up — follow it through.
  5. Refresh your GitHub repo page in the browser. Your files should now appear. Done.
TIP

Future updates are just three commands. Whenever you change a file, run:

$ git add .
$ git commit -m "describe what you changed"
$ git push

If you connect Vercel/Netlify (next section), every push automatically redeploys the live site within 30 seconds.

ALT

Too much terminal? Download GitHub Desktop — a clean clickable app that does all of the above without any commands. Open it, sign in, click "Add Local Repository", point it at your folder, click "Publish repository". That's it.

/CHosting & deployment

Picking a host, and connecting it to GitHub for automatic deploys.

C.1 — Which platform?

PlatformFree tierSpeedBest for
Netlify Yes, generous Fast (global CDN) Recommended for you. Simplest dashboard. Easiest custom-domain flow.
Vercel Yes Fast If you later upgrade to a Next.js build. Also fine for static.
Cloudflare Pages Yes, most generous Fastest Best raw performance, but slightly more technical setup.

I recommend Netlify for your case. Beginner-friendliest, free SSL, free custom domain hookup, and excellent for Arabic / RTL sites.

C.2 — Deploy on Netlify (step by step)

  1. Go to app.netlify.com/signup.
  2. Click "Sign up with GitHub". Authorize when prompted.
  3. Once you land in the dashboard, click "Add new site" → "Import an existing project".
  4. Choose Deploy with GitHub. It'll ask to install the Netlify app on your GitHub. Click Configure → choose "Only select repositories" → pick alsagri-website → Save.
  5. Back in Netlify, your repo will appear in the list. Click it.
  6. On the build settings screen:
    • Branch to deploy: main
    • Build command: leave empty
    • Publish directory: leave empty (or type .)
  7. Click Deploy. Wait ~30 seconds.
  8. You'll get a URL like https://random-name-abc123.netlify.app. Click it. Your site is live. 🎉

C.3 — Rename your free subdomain (optional)

While you're shopping for a real domain, you can claim a nicer Netlify URL:

Netlify dashboard → Site configuration → Domain management → Options → Edit site name

Change to e.g. alsagri-capital → your site becomes https://alsagri-capital.netlify.app.

D.2 — What kind of domain?

For an investor-focused content platform, in order of strength:

  • alsagricapital.com — universal, easy to share, instantly looks professional. My top recommendation.
  • alsagricapital.sa — strong Saudi signal, premium-feeling. Requires Saudi CR or ID via SaudiNIC.
  • alsagri.capital — clever but slightly novelty. Renewals are pricier.

D.3 — Buy the domain

Using Porkbun as the easiest example:

  1. Go to porkbun.com.
  2. Search alsagricapital. Add .com (and any backups like .sa) to your cart.
  3. Create account, pay. Decline all upsells — you don't need their email, web hosting, or "premium DNS." You already have hosting (Netlify).
  4. You now own the domain. The next step is pointing it at Netlify.

D.4 — Connect the domain to Netlify

This is the bit that scares beginners. It's actually 4 clicks + 2 copy-pastes.

  1. In Netlify:

    Site → Domain management → Add a domain

    Type your domain (e.g. alsagricapital.com) → click Verify → click Add.
  2. Netlify will show you two values to copy. They look like this: 
    # For the bare domain (alsagricapital.com)
A record       →  75.2.60.5

# For www.alsagricapital.com
CNAME record   →  your-site.netlify.app
    Keep that tab open.
  3. In Porkbun (or your registrar):

    My Account → Domain Management → Details → DNS Records

  4. Delete any default records that came with the domain (parking pages). Then add two new records:
    TypeHostAnswer / Value
    A(leave blank, or @)75.2.60.5 (use the IP Netlify showed you)
    CNAMEwwwyour-site.netlify.app (use the value Netlify showed you)
    Save.
  5. Wait 5 minutes to 24 hours while DNS propagates around the world. Usually it's 10 minutes.
  6. Back in Netlify, hit Verify DNS configuration. Then click "HTTPS → Provision certificate" (often automatic). This gives you the green padlock.
DNS

What is DNS, in one sentence? The internet's phone book — it turns alsagricapital.com into the IP address of Netlify's servers. The "A record" is the bare domain, the "CNAME" handles the www. version.

/EProfessional polish checklist

Before you tell anyone the URL — go through this.

E.1 — Responsive on mobile & desktop

Open the live URL on your phone. Then on desktop, press F12 (or Cmd+Opt+I on Mac), click the device toolbar icon, and test at iPhone, iPad, and 1440px widths.

E.2 — Arabic / RTL renders correctly

The site already declares <html lang="ar" dir="rtl"> and uses IBM Plex Sans Arabic. Verify on the live site that:

  • Text reads right-to-left.
  • The arrow icons on buttons point in the right direction (←).
  • The reports list isn't mirrored awkwardly.

E.3 — Loading speed

Test at pagespeed.web.dev. Paste your URL → click Analyze. Aim for 80+ on mobile.

Because the current site transpiles JSX in the browser, your first-load score will be in the 60–80 range. Tell me when you want to convert to a Vite build — it'll jump to 95+.

E.4 — Buttons & links

Click everything once. In particular check:

  • Nav links jump to the right sections.
  • The contact section links go to real handles (currently placeholders — give me your real email/LinkedIn and I'll wire them up).
  • Footer year is correct.

E.6 — Favicon & social share image

Two small graphic files make the site feel real.

  • Favicon — the little icon in the browser tab. Use a navy "AC" mark on white. Create one easily at realfavicongenerator.net — drop in a 512×512 PNG, download the bundle, drop the files in your project folder, paste the snippet they give you into your <head>.
  • Social share image (Open Graph) — what shows up when you paste the URL into X or WhatsApp. A 1200×630 PNG with the headline + logo. I can design one for you in this workspace — just ask.
